## Projeler

### İşletim Sistemleri
- **Jubatus OS 2.0** — 64-bit ana sürüm, GNOME masaüstü, jps-64 paket yöneticisi
- **Jubatus Lite 1.0** — 32-bit & 64-bit hafif sistem, XFCE masaüstü
- **Solara OS 1.0** — 64-bit, bağımsız depo, solpkg paket sistemi
- **Jubatus Hurd 1.0** — GNU/Hurd deneysel test sürümü
- **Jubatus Jedi** — Dokunmatik akıllı tahta sürümü (Jubatus Educational Digital Interface)

### Yazılım Araçları
- **Xyronix Backup V3 Pro** — Akıllı delta yedekleme, snapshot sistemi
